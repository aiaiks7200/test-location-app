# 常见问题

## 定位 / 模拟

**Q：开始模拟后，其他 App 定位不变？**
- 确认在「设置 → 开发者选项 → 模拟位置信息应用」里选择了 **test Location**。
- 本 App 同时 mock 了 GPS 和网络定位，但个别 App 会缓存上一次位置，杀掉该 App 重开再试。
- 部分 App（尤其地图类）有自己的定位 SDK 与防模拟逻辑，效果因 App 而异。

**Q：前台服务被系统杀了怎么办？**
- 在电池优化里把 test Location 设为「不优化」/「无限制」。
- 部分国产 ROM 需要允许「自启动」并加入后台白名单。

**Q：为什么弱网下还能选点？**
- 地图与瓦片打包在 `assets/`，离线可用，不依赖在线地图服务。

## 会员 / 试用

**Q：重装 App 会重置 15 天试用吗？**
- 不会。会员/试用状态由服务端按设备码判定，重装后联网检查仍以服务端为准。

**Q：付费后会员加多少天？**
- 月度会员 +30 天、年度会员 +365 天，在当前到期日基础上叠加；已过期则从支付成功时刻起算。

**Q：价格在哪里改、改完要升级 App 吗？**
- 价格由服务端动态下发（`/api/plans`），后台修改后 App 下次打开支付页即生效，**无需升级 App**。

**Q：支付成功但 App 没续上？**
- 支付结果依赖回调 + 轮询。若长时间未生效，重开 App 触发一次 `/api/license/check`；仍异常请联系作者并提供设备码。

## 安装 / 更新

**Q：更新版本提示签名不一致？**
- 说明新 APK 用了不同 keystore 签名。请使用同一 `release.keystore` 构建发版（见 `docs/BUILD.md`）。

**Q：强制升级是怎么触发的？**
- 服务端可为某版本设置 `force_upgrade`，App 鉴权时收到 `must_upgrade` 即引导下载最新 APK。
